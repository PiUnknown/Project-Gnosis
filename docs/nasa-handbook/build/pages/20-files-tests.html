5.1.3

INTRODUCTION.

The repository's second half is evidence: 5,244 lines of tests and roughly 2,200 lines of tracked records and configuration. The test suite is the strongest description of intended behaviour in the tree, and it is more current than the README. It runs entirely offline: HTTP, Redis, Chroma and the hosted model are replaced by fakes, TestClient, fakeredis and monkeypatching. No test contacts GitHub, NVIDIA or a live Redis instance. The design and memory files marked local, ignored exist in this working tree but in no clone (figure 5.1-2).
