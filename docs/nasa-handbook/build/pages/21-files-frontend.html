5.2.1

INTRODUCTION.

The frontend is a Vite project nested inside the backend repository. Eight files under src/ matter; one of them, pages/ResultsPage.tsx, is a complete earlier implementation that nothing imports. The rest is build configuration, brand imagery and an imports folder preserving the Figma hand-off; those archives are not compiled into the application but are retained as design provenance (figure 5.2-1).
