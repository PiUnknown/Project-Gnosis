8.1.1

INTRODUCTION.

This register lists defects and limitations confirmed by reading the working tree. Each entry names a file, the symptom, and the class of harm. None was fixed for this handbook. Severity is an engineering judgement, not a project rating: HIGH means a lost deliverable, a failed run on a supported path, or a credential exposure; MEDIUM means misleading output or an operational trap; LOW means dead code, stale text or cosmetic drift (figure 8.1-1).
