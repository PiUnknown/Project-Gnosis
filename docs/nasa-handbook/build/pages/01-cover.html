This handbook describes the Project Gnosis code-archaeology system as it exists in the working tree at commit 4135A25, dated 16 October 2026. It is written for the engineer who must operate, extend or review the system without prior knowledge of it.

The system accepts a public GitHub repository address and returns a grounded architectural document: a file manifest, symbol tables, an import graph, per-file complexity scores, a vector index of semantic code chunks, and natural-language explanations produced by a hosted language model. Seven deterministic stages surround one non-deterministic stage. A shared state object carries the work between them.

Every statement is classified. OBSERVED means read from executable source in this tree. DOCUMENTED means asserted by a repository document or commit and not independently exercised. INFERRED means a conclusion drawn from structure, with its basis named. Where a document and the code disagree, the code is described and the disagreement is recorded.
