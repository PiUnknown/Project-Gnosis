8.2.3

Deliberate Simplifications.

Figures are redrawn as single-colour line art; no product screenshots are included. The catalogue gives non-empty line counts and one-line responsibilities, not a function-by-function inventory. Pipeline examples are structural: no real repository was analysed, so no timing, cost or output-quality measurement is offered. Secret values and the contents of .env are excluded; only variable names appear. Commands not listed on 7.1-1 are described from code and marked as unexecuted.
