5.1.1

INTRODUCTION.

This catalogue covers every tracked file at the analysed commit, plus two local files that are present but not yet tracked. It excludes generated and vendored material: the virtual environment, node_modules, build output, Chroma persistence, run outputs, caches and this handbook. Line counts are non-empty lines at the working tree, not logical statements. The purpose is orientation: a reader should be able to name the file that produces any value seen in the output (figure 5.1-1).

5.1.2

BACKEND MODULES.

Thirty-three Python modules carry the backend. src/parsers turns syntax into dataclasses; src/utils supplies everything that talks to the outside world; src/agents holds the seven stages; src/api adds transport and persistence. Empty __init__.py files are omitted from the table.
